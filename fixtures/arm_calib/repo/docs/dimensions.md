# The arm's dimensions (approximate)

From the arm's general dimensions drawing ("Arm general dimensions", Onyx, 9/29/26, section A-A at 1:5), in millimetres, measured along the arm from the base:

| Between | Length (mm) |
|---|---|
| The base plate to the first joint axis | 66.5 |
| The next two segments | 220.5, 220.5 |
| The last segment, to the end | 157 |

Offsets across the arm shown on the drawing: 16.25, 79.75 and 90.75 mm.

These are nominal: how the arm is meant to be, not how this one is. The URDF (`onyx_arm.urdf`) is the CAD's model of the same arm.
