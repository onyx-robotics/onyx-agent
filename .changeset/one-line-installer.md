A one-line installer: `curl -fsSL https://onyxresearch.ai/install.sh | bash` puts this machine's `onyx` binary in `~/.local/bin` and the skills for Claude Code in `~/.claude/skills`, each checked against the release's `SHA256SUMS` (`ONYX_VERSION` installs another release). Releases carry it as `install.sh`, with the skills as `skills.tar.gz`.
