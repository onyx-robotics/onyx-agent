Research runs take each agent's instructions from its skill: `skills/onyx-research-base`, `-varop` and `-worker`, built into `onyx` and installed by `onyx setup`. Agents can only do their own job: the base agent and the var-op read and run nothing but `onyx research`, and a worker edits code and runs only `onyx research` and read-only git, so every computation is an experiment on an endpoint. The var-op starts each wake afresh from the base agent with the board and its journal, so a wake costs the same at the end of a run as at its start. Each endpoint has a time limit per experiment for the run, a hard cutoff sent with every experiment to its driver (`time_limit_s`), which the user changes with `onyx research limit`. Experiments say what they're for (`--kind`), measurement changes are hypotheses of their own (`propose --measurement`, and results measured differently are never compared), and a hypothesis can be finished without an experiment. A refused command no longer stalls an agent: it's told which command was refused, and the var-op is told why a worker stopped. A run's experiments are held to twice its endpoints' capacity, and runs sharing an endpoint get a fair share of it. The quick evaluation and the turn time limit are gone.
